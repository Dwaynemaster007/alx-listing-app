# 🏠 ALX Listing App

The first version of an Airbnb-style listing page, built with **Next.js**, **TypeScript** and **Tailwind CSS** for the **ALX ProDev Frontend** programme.

![Next.js](https://img.shields.io/badge/Next.js-000000?style=flat-square&logo=nextdotjs&logoColor=white)
![React](https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-06B6D4?style=flat-square&logo=tailwindcss&logoColor=white)

## What's inside

- Reusable, typed `Button` and `Card` components (`components/common/`)
- Shared constants and TypeScript interfaces
- A home page that renders listing cards
- Tailwind CSS configuration

Later milestones build on this: [`alx-listing-app-00`](https://github.com/Dwaynemaster007/alx-listing-app-00), [`alx-listing-app-detail`](https://github.com/Dwaynemaster007/alx-listing-app-detail), [`alx-listing-app-03`](https://github.com/Dwaynemaster007/alx-listing-app-03), [`alx-listing-app-04`](https://github.com/Dwaynemaster007/alx-listing-app-04) and [`alx-listing-app-deployed`](https://github.com/Dwaynemaster007/alx-listing-app-deployed).

## Run it

```bash
git clone https://github.com/Dwaynemaster007/alx-listing-app.git
cd alx-listing-app
npm install
npm run dev
```
